Technical Architecture & Impact

3-Tier System Architecture

Designed for massive concurrency and real-time state synchronization across rural kiosks and central servers.

Client Layer

PWA React frontend optimized for low-bandwidth mobile networks and Kiosk terminals. Includes BHASHINI API integration.

Application Logic

Node.js/Express.js handling JWT auth, SMS event triggers, and queuing the XGBoost inference model.

Persistence

MongoDB for agricultural metadata and fast writes. AWS S3 for storing crop quality assaying imagery.
